## Data description

This directory contains representative E-3SAT instances constructed
using the TBL–MRE framework described in the paper.

### CNF instances
- The `.cnf` files correspond to hard satisfiable E-3SAT instances.
- These instances are provided for structural inspection and solver
  verification.
- Full large-scale datasets used for the scaling experiments will be
  made available separately (e.g., via Zenodo).

### Solver logs
- The included MiniSat log files record solver behavior on selected
  hard instances.
- These logs are provided for reference only and were obtained by
  externally terminating the solver after prolonged execution.
